# Hikmah

A narrated wisdom library: packages from the Qur'an and tafsir, the classical scholars, and the great thinkers, with Nigerian wisdom. Installable as a phone app and playable offline.

Open: https://ssadeeqib-arch.github.io/hikmah/

Sources: Arabic text from Tanzil (Uthmani). Translation: Saheeh International. Recitation: Mishary Rashid Alafasy. Narration is a synthetic voice.
